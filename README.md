# Nutri-Track

> 운동량에 반응하는 지능형 식단 가이드 플랫폼

## 1. 프로젝트 개요
- 목적: 사용자의 실시간 운동 소모 칼로리를 반영하여 최적의 탄/단/지 섭취량을 가이드
- 핵심 가치: 데이터 기반의 정밀 영양 설계 
- 기술 스택: Java 17, Spring Boot 3.x, JPA, MySQL, Redis, React Native (Expo).

## 2. 핵심 기능 (Requirements)
- FR-01: 신체 정보 기반 기초대사량(BMR) 및 목표 영양소 자동 산출.
- FR-02: 운동 기록(소모 칼로리) 연동을 통한 실시간 식단 가이드 업데이트.
- FR-03: 공공 API 기반 식품 영양 성분 검색 및 식단 로그 기록.


## 3. 데이터베이스 설계 (ERD)
- Users: 신체 정보 및 목표 설정.
- Foods: 공공 데이터 기반 식품 사전.
- Meal_Logs: 일일 식단 섭취 기록.
- Workout_Logs: 운동 수행 데이터 및 소모 칼로리.
